# Lumina

Lumina is a responsive movie and TV discovery platform built to help users browse, search, and save entertainment content in one polished interface. It is designed as a resume-ready project that demonstrates real-world product thinking, API integration, state management, and a clean user experience.

## What It Does

The app lets users explore trending, popular, top-rated, and currently playing titles, then move into dedicated movie, TV show, and person detail pages for deeper context. Users can search across titles, filter by genre, and keep a personal watchlist that persists in the browser.

## How It Works

Lumina uses The Movie Database for content data and builds the experience around a few simple flows:

1. Browse curated home sections to discover new titles.
2. Open a movie, TV show, or person page to view details, cast, recommendations, and related information.
3. Use search and genre filters to narrow down results quickly.
4. Add items to the watchlist to keep track of content for later.
5. For supported titles, switch between available playback sources from the media detail page.

The interface is built to feel fast and reliable, with loading states, error recovery, and responsive layouts for desktop and mobile.

## Key Highlights

- TMDB-powered browsing and search
- Dedicated pages for movies, TV shows, and people
- Personal watchlist with local persistence
- Genre-based filtering and recommendations
- Responsive UI with a modern cinematic look
- Graceful loading and network error handling

## Tech Stack

- React and TypeScript
- Vite
- Tailwind CSS
- TanStack Query
- React Router
- shadcn/ui and Radix UI components

## Setup

To run the project locally, install the dependencies, add a TMDB API key in the environment, and start the development server.

## Summary

Lumina is best described as a modern entertainment discovery and playback hub. It shows how a product can combine content browsing, search, watchlist management, and media detail flows into a single polished application.
